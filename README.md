# Social Media Sentiment & Engagement Analysis

## Project Overview

The Social Media Sentiment & Engagement Analysis Dashboard is an interactive Power BI project designed to analyze social media posts, sentiment categories, engagement, platforms, countries, and sentiment trends over time.

The dashboard provides a visual overview of social media activity and helps identify patterns in sentiment and engagement.

## Objectives

- Analyze social media sentiment.
- Understand platform-wise post distribution.
- Analyze country-wise posts.
- Compare likes and retweets.
- Analyze engagement across platforms.
- Study sentiment trends over time.
- Present important findings through an interactive Power BI dashboard.

## Dataset

The project uses a social media sentiment dataset containing information such as:

- Post ID
- Sentiment
- Platform
- Country
- Likes
- Retweets
- Timestamp
- Text
- Hashtags
- User

## Tools & Technologies

- Microsoft Power BI
- Power Query
- DAX
- Data Analysis
- Data Visualization

## Dashboard Features

### KPI Cards

- Total Posts
- Positive Sentiment %
- Total Likes
- Total Retweets

### Visualizations

- Posts by Sentiment
- Posts by Platform
- Posts by Country
- Engagement by Platform
- Sentiment Distribution
- Sentiment Over Time
- Likes vs Retweets by Platform

### Key Insights

The dashboard contains a dedicated Key Insights page summarizing the major findings from the analysis.

## Key Results

- Total Posts: 732
- Positive Sentiment: 6.1%
- Total Likes: 31K
- Total Retweets: 16K
- Engagement varies across social media platforms.
- The dataset contains multiple sentiment categories.
